# Active RAG Codebase Assistant

## Overview

An AI-powered assistant that allows developers to ask
natural-language questions about Python codebases.

The system retrieves relevant source code, generates
context-aware explanations and provides source citations.

## Project Goals

- Understand Python repositories.
- Retrieve relevant code snippets.
- Generate answers grounded in source code.
- Provide file and line-number citations.
- Improve retrieval through hybrid and active retrieval.

## Development Experiments

- A: Fixed-size chunking + vector retrieval.
- B: AST-aware chunking + vector retrieval.
- C: AST-aware chunking + hybrid retrieval.
- D: AST-aware chunking + hybrid retrieval + active retrieval.
